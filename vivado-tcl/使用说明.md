# vivado-tcl 使用说明

## 这是什么

一个**执行型 skill**，专门用于生成和执行 Vivado/Vitis TCL 脚本。覆盖 FPGA 设计的完整自动化流程：工程创建、综合、布局布线、比特流生成、硬件烧录、IP Integrator、调试核插入。

**注意**：此 skill 只负责**生成和执行 TCL 脚本**，不负责分析 Vivado 输出或报告。分析报告请用 `vivado-analysis`。

---

## 适用场景

| 场景 | 说明 |
|------|------|
| 新建 Vivado 工程 | Project Mode 脚本自动创建工程、添加源文件、约束文件 |
| 批量综合/实现 | Non-Project Mode 脚本，适合 CI/CD 自动化 |
| IP Integrator（Block Design） | 自动创建 Block Design、添加 IP、AXI 互联、生成 wrapper |
| 硬件烧录 | 自动连接硬件、烧录比特流、加载调试探针 |
| ILA 调试核插入 | 创建 ILA、连接时钟和探针信号、导出 .ltx |
| 仿真自动化 | xsim 或第三方仿真器（Questa/ModelSim/VCS）批处理 |

## 两种设计流程

| 模式 | 适用场景 | 关键命令 |
|------|---------|---------|
| **Project Mode** | 交互式开发、GUI 友好 | `create_project` → `add_files` → `launch_runs` → `wait_on_run` |
| **Non-Project Mode** | CI/CD 自动化、脚本驱动 | `read_verilog` → `synth_design` → `opt_design` → `place_design` → `route_design` |

> ⚠️ **绝对不能混用**两种模式的命令。

---

## 快速参考

### Project Mode 全流程
```tcl
create_project myproj ./myproj -part xc7z020clg484-1
add_files {./src/top.v ./src/sub.v}
add_files -fileset constrs_1 ./constraints/timing.xdc
launch_runs synth_1 -jobs 8
wait_on_run synth_1
launch_runs impl_1 -to_step write_bitstream -jobs 8
wait_on_run impl_1
```

### Non-Project Mode 全流程
```tcl
read_verilog {./src/top.v}
read_xdc ./constraints/timing.xdc
synth_design -top top -part xc7z020clg484-1
opt_design
place_design
route_design
write_bitstream -force ./output/top.bit
```

### 执行方式
```bash
# 批处理（推荐）
vivado -mode batch -source script.tcl

# 带参数
vivado -mode batch -source script.tcl -tclargs "PART=xc7z020"
```

## 注意事项

1. **执行环境**：需要本机安装了 Vivado，且 `vivado` 在 PATH 中
2. **两种模式不混用**：Project Mode 和 Non-Project Mode 的命令结构完全不同
3. **关键输出文件**：`vivado.log`（日志）、`vivado.jou`（TCL 日志，可复用）、`*.dcp`（检查点）
4. **写 checkpoint**：Non-Project Mode 建议在每个关键阶段后写 checkpoint，出问题可恢复
