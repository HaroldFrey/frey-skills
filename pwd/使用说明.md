# /pwd — 查看当前目录与 Session 目录

## 功能
打印当前工作目录，同时列出当前 session 涉及的所有关键目录（配置目录、Skills 目录、工程目录）。

## 使用方式
在 Claude Code 中输入 `/pwd` 即可。

## 输出示例
```
📍 当前目录：D:\Some\Project
⚙️ 配置目录：C:\Users\<用户名>\.claude\
📦 Skills 目录：C:\Users\<用户名>\.claude\skills\
📁 工程目录：D:\Some\Project
```

> 所有路径由 skill 动态获取（环境变量 + 命令），不依赖特定用户名或盘符，可跨电脑使用。
