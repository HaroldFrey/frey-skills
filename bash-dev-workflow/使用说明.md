# /bash-dev-workflow — Bash 脚本开发全流程

## 功能
编排型 skill，管理 Bash 脚本从需求分析到交付的完整流程。支持单文件和多文件项目。内部自动调用 `/bash-defensive-patterns` 确保代码质量。

## 触发方式
- 手动：`/bash-dev-workflow`
- 自动匹配：说"开发脚本"、"写Bash"、"脚本开发流程"

## 流程阶段

| 阶段 | 说明 | 检查点 |
|------|------|:--:|
| 0. 需求分析 | 不限轮次追问，生成需求文档 | 🛑 强制确认 |
| 1. 设计方案 | 10 个小节的完整设计文档 | 🛑 |
| 2. 编写代码 | 加载防御性编程规范 + 语法解析 | 🛑 |
| 3. 代码审查 | 6 维审查 + 14 条规范逐项 | 🛑 |
| 4. 问题追踪 | 汇总问题，标注所属文件 | 🛑 |
| 5. 迭代 | 从设计开始逐阶段重新推进 | 🛑 |
| 6. 最终审查 | 完整性 + 规范 + 测试建议 | 🛑 |
| 7. 全面检查 | 代码与所有文档交叉验证 | 🛑 |

## 模式
- 🔧 手动（默认）：每个检查点等待确认
- 🤖 自动：`/bash-dev-workflow --auto`

> ⚠️ 需求确认阶段不受模式影响，必须人工确认。
