# 设计文档 — file-stats

## 功能概述
统计指定目录下的文件信息：总数、分类（按扩展名）、大小分布、Top N 大文件。

## 参数
| 参数 | 必需 | 默认值 | 说明 |
|------|:--:|------|------|
| `<dir>` | 是 | — | 要扫描的目录 |
| `-n, --top N` | 否 | 5 | 显示 Top N 大文件 |
| `-d, --dry-run` | 否 | false | 预览模式 |
| `-v, --verbose` | 否 | false | 详细输出 |
| `-h, --help` | 否 | — | 帮助 |

## 依赖
- `find`（系统自带）
- `du`（系统自带）
- `sort`（系统自带）
- `wc`（系统自带）
