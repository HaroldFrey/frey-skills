## 问题列表

### P-001：macOS 环境下 du -h 不可用
- **发现阶段**：代码审查
- **严重程度**：🟢低
- **问题描述**：macOS 的 `du` 不支持 `-h` 参数，需用 `-k` 并手动转换
- **建议方案**：加平台检测，macOS 用 `du -k | awk '{printf "%.1fM", $1/1024}'`
- **解决状态**：不修复（Windows/Git Bash/Linux 均为 GNU du，不影响）
- **处理方式**：自动
- **解决说明**：目标用户环境为 Linux/Git Bash，忽略

### P-002：大量文件时 xargs 可能溢出
- **发现阶段**：代码审查
- **严重程度**：🟢低
- **问题描述**：文件数超极多（10万+）时 `xargs` 可能报参数过长
- **建议方案**：加 `xargs -n 500` 限制每次处理的文件数
- **解决状态**：不修复（常规项目目录不会超限）
- **处理方式**：自动
- **解决说明**：适用于常规项目目录，极端场景用户自行调整
