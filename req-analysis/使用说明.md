# /req-analysis — 需求分析

## 功能
独立的预处理 skill。通过不限轮次追问理清所有需求细节，生成结构化需求文档。任何项目开始前都可以先调用此 skill 明确需求。

## 触发方式
- 手动：`/req-analysis`
- 自动匹配：说"需求分析"、"理清需求"、"明确需求"、"需求澄清"

## 流程
1. 理解初始需求
2. 不断追问（不限轮次），覆盖：功能 / 接口 / 性能 / 边界 / 约束 / 优先级
3. 生成需求文档（功能需求表 + 非功能需求 + 接口规格 + 约束 + 确认 checkbox）
4. 🛑 用户确认

> ⚠️ 无论手动/自动模式，必须用户确认后才结束。

## 与其他 Skill 的关系
可独立使用，也可被 `/bash-dev-workflow` 和 `/sv-dev-workflow` 的阶段 0/A0 内嵌调用。
