## 项目模式识别

### 2026-07-28 | 来源：06_code（裸机自动化测试框架）

**SSH 双机编排型 Bash 项目**。特征：
- 控制机器通过 SSH 远程操控执行机器
- 含退出码传递链（cmd → SSH → control）
- 重启恢复机制（reboot + wait_for_reboot）
- 断点续跑
- 测试完成后自动取回日志、生成报告

分析此类项目时应额外关注：
- SSH 退出码约定（0/124/255 各自含义）
- 控制机器与执行机器的配置一致性（TARGET、端口、工作目录）
- 远程命令的幂等性设计（重试时可能重复执行）

## 分析维度补充

### 2026-07-28 | 来源：06_code（裸机自动化测试框架）

**退出码传递链追踪**。对于多层调用的脚本项目，应追踪退出码从最底层到顶层的完整传递路径，标注每层对退出码的拦截/改造行为：
- 最底层（case 命令）→ 中间层（cmd_time.sh）→ SSH 层 → 顶层（control.sh）
- 标注哪些退出码被吞掉（如 cmd_time.sh 吞掉 case 的 134/139）
- 标注哪些退出码被改造（如 timeout 命令的 124 被 cmd_time.sh 透传）
- 标注 SSH 自身退出码 vs 远程命令退出码的区别
