# /commit_push — 智能推送到 GitHub

## 功能
自动完成 `git add -A` → `git commit` → `git push` 流程。首次推送提醒手动创建仓库，非首次直接更新。

## 触发方式
- 手动：`/commit_push`
- 自动匹配：说"推送代码"、"推送到GitHub"、"git push"

## 使用示例

### 日常更新
```
/commit_push
```
自动暂存 → 生成 commit message → 推送 main 分支。

### 指定分支
```
/commit_push dev
推送到 feature/new-ui
```

### 首次推送
```
/commit_push
→ ⚠️ 未检测到 origin，请在 GitHub 手动创建空仓库
→ 输入仓库地址
→ 配置 origin → 推送
```

## 工作流程
```
检查 git 仓库 → 检查 remote → git add -A → 生成 commit → git push
```
