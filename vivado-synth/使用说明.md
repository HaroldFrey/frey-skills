# vivado-synth 使用说明

## 这是什么

一个**决策型 skill**，专门帮助你在 Vivado 综合阶段做出正确的策略选择和属性配置。覆盖 `synth_design` 全部选项、综合属性（DONT_TOUCH、KEEP、RAM_STYLE 等）、Block-Level Synthesis、OOC（Out-of-Context）综合、增量综合和 RTL Linter。

**注意**：此 skill 提供**决策知识**——什么时候用什么策略、什么属性。实际执行 TCL 命令请用 `vivado-tcl`。

---

## 适用场景

| 场景 | 说明 |
|------|------|
| 选择综合策略 | 面积优先？性能优先？还是快速迭代？ |
| 控制资源推断 | 强制/阻止使用 BRAM、DSP、SRL |
| 保留关键逻辑 | 防止优化掉调试信号或关键寄存器 |
| 层次化优化 | 控制 hierarchy 展平程度 |
| OOC 综合 | 大 IP 核独立综合 |
| 增量综合 | 只重新综合修改过的部分 |
| RTL Lint | 综合前代码质量检查 |
| FSM 编码 | 选择状态机编码方式 |

## 核心决策速查

### 综合策略选择

| 你的需求 | 选哪个策略 |
|---------|-----------|
| 第一次跑，看看效果 | `default` |
| 快速迭代调试 | `runtimeoptimized` |
| 资源不够用了 | `AreaOptimized_high` |
| 时序过不了 | `PerformanceOptimized` |
| 布线拥塞 | `AlternateRoutability` |
| 面积极限优化 | `LogicCompaction` |

### 常用属性速查

| 你的需求 | 用什么属性 | 值 |
|---------|-----------|-----|
| 保护寄存器不被优化 | `DONT_TOUCH` | `TRUE` |
| 保护信号不被吸收进 LUT | `KEEP` | `TRUE` |
| 保持模块层次 | `KEEP_HIERARCHY` | `SOFT` |
| 强制用 Block RAM | `RAM_STYLE` | `block` |
| 强制用 Distributed RAM | `RAM_STYLE` | `distributed` |
| 阻止用 DSP | `USE_DSP` | `no` |
| 标记 ILA 调试信号 | `MARK_DEBUG` | `TRUE` |
| CDC 同步寄存器 | `ASYNC_REG` | `TRUE` |
| FSM 独热码编码 | `FSM_ENCODING` | `one_hot` |

## synth_design 关键选项

```tcl
synth_design \
  -top <top_module> \
  -part <part_number> \
  -flatten_hierarchy rebuilt \       # none/full/rebuilt
  -directive PerformanceOptimized \  # 综合策略
  -fsm_extraction one_hot \          # FSM 编码
  -resource_sharing on \             # 资源共享
  -max_dsp 32 \                      # 限制 DSP 数量
  -max_bram 64 \                     # 限制 BRAM 数量
  -shreg_min_size 5 \                # SRL 最小长度
  -global_retiming on                # 全局重定时
```

## 注意事项

1. **属性优先级**：RTL 和 XDC 同时设置同一属性不同值时，**XDC 优先生效**
2. **KEEP/DONT_TOUCH**：必须在 RTL 中设置（等 XDC 加载时目标已被优化掉了）
3. **OOC 限制**：OOC 模块不支持增量综合，且不能包含 AMD IP
4. **综合阶段时序不准**：综合后的时序报告用的是估算布线延迟，只有布局布线后的时序才准确
