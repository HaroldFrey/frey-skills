# /skill-maker — Skill 制作工作流

## 功能
编排型 skill。根据你的描述创建自定义 skill，引导试用、反馈、迭代，直到满意。自动生成 `skill.md` + `使用说明.md`。

## 触发方式
- 手动：`/skill-maker`
- 自动匹配：说"制作skill"、"创建skill"、"新建skill"、"生成skill"

## 流程

| 阶段 | 说明 | 检查点 |
|------|------|:--:|
| 1. 理解需求 | 追问 → 生成确认清单 | 🛑 |
| 2. 生成 Skill | 创建 skill.md + 使用说明.md → 展示内容 | 🛑 |
| 3. 试用 | 提示用户 /命令 试用 | 🛑 |
| 4. 反馈 | 收集反馈 + AI 主动给出改进建议 | — |
| 5. 迭代 | 修改 → 再试 → 循环 | — |
| 6. 完成 | 用户满意 | — |

## 生成的文件
```
skills/<skill名>/
├── skill.md          ← AI 执行的指令
└── 使用说明.md        ← 人类可读的说明
```
