# /git-pull — 检查远程更新并同步本地

## 功能
检查 git 仓库的远程是否有新提交，有则自动 `git pull` 同步，无则告知已是最新。支持一次检查多个目录。

## 触发方式
- 手动：`/git-pull`
- 自动匹配：说"检查更新"、"同步仓库"、"拉取最新"、"git pull"

## 使用示例

### 检查当前目录
```
/git-pull
```
自动检查当前所在目录的远程仓库状态。

### 指定单个目录
```
/git-pull D:\Stduy\WSL_Use
```

### 一次检查多个目录
```
/git-pull D:\Stduy\WSL_Use D:\Stduy\AI-Agent C:\Users\28968\.claude\skills
```
依次检查每个目录，最后输出汇总表。

## 工作流程
```
解析参数（无参数=当前目录，有参数=逐个处理）
  → 确认是 git 仓库
  → git fetch 获取远程状态（不修改本地）
  → git status 对比 ahead/behind
  → 远程有更新 → git pull 同步
  → 汇总结果
```

## 注意事项
- **本地有未提交修改时**：不会擅自覆盖，会先询问你处理方式（提交/暂存/跳过）
- **pull 有冲突时**：停止并展示冲突文件，由你决定如何解决
- **网络失败时**：自动重试 3 次（间隔 10 秒），仍失败则提示手动操作
