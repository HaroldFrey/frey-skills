# verilog-sv-language 使用说明

## 这是什么

一个**专家级知识型 skill**，封装了 Verilog 和 SystemVerilog 的完整编码规范（遵循 IEEE 1800-2017 标准）。当你编写或修改 RTL 代码时，AI 会自动遵循这套规范，生成可综合的、风格正确的 HDL 代码。

**不是仿真器，也不连接 EDA 工具**——它是一个"RTL 编码导师"，确保 AI 写出来的代码符合工业级标准。

| 场景 | 说明 |

## 核心能力

### 1. Always 块选择

skill 强制正确使用 SystemVerilog 的三种 always 块：

| 块类型 | 用途 | 赋值方式 |
|--------|------|---------|
| `always_ff` | 时序逻辑（触发器） | `<=`（非阻塞） |
| `always_comb` | 组合逻辑 | `=`（阻塞） |
| `always_latch` | 有意的锁存器（极少用） | `=`（阻塞） |

**skill 禁止的行为**：
- ❌ 使用原始的 `always @*`
- ❌ 在 `always_ff` 中混用阻塞赋值
- ❌ 组合逻辑中缺少默认赋值导致推断锁存器

### 2. 参数化设计

生成的所有模块都自动支持参数化：

```systemverilog
module sync_fifo #(
  parameter int DATA_WIDTH = 8,                // 可配置
  parameter int DEPTH = 16,                     // 可配置
  localparam int ADDR_WIDTH = $clog2(DEPTH)     // 自动推导
) (/* ports */);
```

### 3. 接口（Interface）定义

支持自动生成 AXI-Stream、AXI-Lite、Memory-Map 等接口：

- 自动创建 master / slave / monitor modport
- 内置握手机制（`wait_for_handshake()`）
- 完整的 TID/TDEST/TUSER 等 sideband 信号

### 4. Package 和类型系统

自动创建可复用的 package，包含：
- `typedef enum` / `typedef struct`
- 共用函数（如 `clog2`、`reverse_bits`）
- 全局常量定义

### 5. 综合属性支持

自动添加厂商特定的综合属性：

| 厂商 | 常用属性 |
|------|---------|
| Xilinx | `ASYNC_REG`、`KEEP`、`RAM_STYLE`、`FSM_ENCODING` |
| Intel | `ramstyle = "M20K"` |

## 代码规范速查

skill 强制遵循以下编码规范：

| 规则 | 要求 | 反例 |
|------|------|------|
| 端口声明 | 每行一个端口 | 多端口挤在一行 |
| 数据类型 | 用 `logic` 代替 `wire`/`reg` | `wire [7:0] data;` |
| 全零/全一 | 用 `'0` / `'1` | `8'h00` |
| 命名风格 | snake_case | camelCase |
| 时序逻辑 | `<=` 非阻塞赋值 | `=` 阻塞赋值 |
| 组合逻辑 | `=` 阻塞赋值 | `<=` 非阻塞赋值 |
| 默认赋值 | 组合逻辑开头先设默认值 | 漏掉某个分支 |
| 参数 | `parameter` 用于可配值，`localparam` 用于推导值 | 混用 |

## 注意事项

1. **仅可综合子集**：skill 生成的代码针对 FPGA/ASIC 综合，不包含不可综合的仿真构造
2. **需要仿真器**：要验证生成的代码，需要 Verilator / Icarus / 商用仿真器
3. **厂商差异**：综合属性部分 Xilinx 和 Intel 写法不同，生成时会尽可能标注
4. **不可替代人工审查**：skill 确保代码风格正确，但时序和功能正确性仍需人工验证
