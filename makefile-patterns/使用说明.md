一个**规范型 skill**，封装了 Makefile 的各种常见模式和最佳实践。当需要创建构建系统、自动化工作流、发布流程时，AI 会自动遵循这些模式。

## 核心模式速查

### 1. 基本结构
```makefile
PROJECT := myproject
VERSION := $(shell git describe --tags --always 2>/dev/null || echo "dev")

.PHONY: help
help:  ## 第一个 target 是默认 target
	@echo "Available targets: ..."

.PHONY: build test clean
build: ## 构建项目
	...
```

### 2. 自文档化 Help
```makefile
.PHONY: help
help: ## 显示帮助
	@grep -E '^[a-zA-Z_-]+:.*?## .*$$' $(MAKEFILE_LIST) | sort | \
		awk 'BEGIN {FS = ":.*?## "}; {printf "%-20s %s\n", $$1, $$2}'

build: ## 构建项目
test:  ## 运行测试
clean: ## 清理产物
```

### 3. 环境变量（可覆盖默认值）
```makefile
CONFIG ?= Release
PORT   ?= 8080
JOBS   ?= $(shell nproc)
```

### 4. 平台检测
```makefile
ifeq ($(shell uname),Darwin)
    OS  := macos
    SED := sed -i ''
else
    OS  := linux
    SED := sed -i
endif
```

### 5. Dev Loop（开发循环）
```makefile
.PHONY: dev kill run
dev: kill build run  ## 快速迭代：停掉→构建→运行
kill:
	@pkill -x "$(APP)" 2>/dev/null || true
run:
	@./$(APP)
```

### 6. 品质门禁
```makefile
.PHONY: qa
qa: fmt lint test  ## 提交前全部检查
```

## 反模式（禁止事项）

| ❌ 不要 | ✅ 应该 |
|--------|--------|
| 忘记 `.PHONY` | 所有非文件 target 都加 `.PHONY` |
| `cd` 不用 `&&` | 每行是独立 shell，必须 `cd dir && cmd` |
| 混用 tab 和空格 | Makefile 必须用 tab 缩进 |
| 硬编码路径 | 用变量 + `?=` 允许覆盖 |
| 不加 `| cat` 的 Xcode 命令 | `xcodebuild ... build | cat` |

## 注意事项

1. **Tab 缩进**：Makefile 的 recipe 行必须用 tab 开头，不能用空格
2. **每行独立 shell**：管道和重定向在同一行内有效，跨行需 `&&` 或 `; \`
3. **变量用 `?=` 设默认值**：允许用户通过环境变量覆盖
4. **GNU Make**：本 skill 针对 GNU Make，不适用于 BSD Make 或 Nmake
