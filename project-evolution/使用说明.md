# project-evolution — 项目迭代演进记录

记录项目每次会话/版本的修改、决策和问题，生成结构化 ITERATION_LOG.md。

## 触发方式

- **手动**：`/project-evolution` 或 `/project-evolution v2.0`
- **自动**：开发会话结束时如检测到文件变更，主动提示
- **详细模式**：`/project-evolution --detail`（逐条交互确认）

## 记录内容

| 维度 | 说明 |
|------|------|
| 变更摘要 | 文件变更清单（新增/修改/删除） |
| 变更详解 | 行级 diff + 改前/改后对比 |
| 设计决策 | 每个重要变更的"为什么" |
| 问题追踪 | 发现 → 讨论 → 修复 → 验证 |
| 架构变更图 | ASCII 架构图的前后对比 |
| 流程演进图 | 流程的演进路径 |

## 输出

项目根目录下的单一文档 `ITERATION_LOG.md`，持续追加：

```
ITERATION_LOG.md
  ├── 🏷️ 迭代 — v1.0（2026-07-21）
  │     ├── 变更清单
  │     ├── 变更详解（含决策原因）
  │     ├── 架构变更图
  │     ├── 流程演进图
  │     └── 问题追踪
  │
  ├── 🏷️ 迭代 — v1.1（2026-07-25）
  │     └── ...
  └── ...
```

## 使用示例

### 手动记录

```
/project-evolution v2.0
```

### 详细交互模式

```
/project-evolution --detail
```

### 会话结束时自动提示

```
📝 检测到 3 个文件变更。是否记录到 ITERATION_LOG.md？
→ 回复"是"自动生成
```
